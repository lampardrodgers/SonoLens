# 声镜 SonoLens · 音乐可视化分析

> 听见的，都看得见。

**声镜 SonoLens** 是一个在本机运行的音乐可视化分析工具。拖入一首歌，它会用 AI 模型和数字信号处理把作品逐层拆开：
- 乐器分离成 6 轨
- 频谱与音高
- 节拍和鼓组
- 调性与和弦进行
- 曲式结构与重复段
- 响度和动态
- 立体声像
- 自动扒谱输出 MIDI

结果在一个黑金风格的网站里展示，有数十种可交互的图表。
打开一首歌首先看到的是「流光」：把音乐实时画成一幅流动的星云，同时能读出氛围、调性和弦、节奏、乐器进出和全曲行进。
它还会把整首歌自动编排成逐章讲述的「影院模式」，30 种动态场景随音乐实时演出，可以直接录成 1080p 视频。
所有分析都在本机完成，音频不会上传。
可选接入大模型（Claude / OpenAI / Gemini / DeepSeek / Kimi / Grok），为整首歌写文字解析、逐章解说和随播放出现的实时解说字幕。

## 快速开始

```bash
./run.sh                      # 首次会自动建 .venv 并安装依赖，然后启动网站
```

打开 <http://localhost:44100>（端口取自 CD 音质的采样率 44.1 kHz），把音频拖进页面即可开始分析。
分析完成后，点右上角的 **▶ 影院模式**。

命令行批量分析：

```bash
./run.sh analyze song1.mp3 song2.flac          # 或：.venv/bin/python -m musicviz analyze ... --force
```

可选参数：
- `--stems htdemucs_6s|htdemucs|htdemucs_ft|none`
- `--no-midi`
- `--no-melody`
- `--force`（忽略缓存重新分析）

依赖：
- Python 3.11
- ffmpeg（`brew install ffmpeg`）
- 首次运行会下载 Demucs、beat_this 和 basic-pitch 的模型权重。

## 分析内容

| 模块 | 内容 |
|---|---|
| 乐器分离 | Demucs htdemucs_6s 拆成人声、鼓、贝斯、吉他、钢琴、其他：每轨可独奏/静音/调音量，并提供能量流图和每轨波形 |
| 频谱 | 对数 STFT、Mel、CQT 音高谱、色度图、谱质心/带宽/滚降/平坦度、频段能量占比、长时平均频谱 |
| 节奏 | beat_this 节拍和小节检测、BPM 曲线、起音强度、节拍稳定度、鼓组（底鼓/军鼓/镲）逐拍网格 |
| 和声 | 调性（含关系大小调判别）、逐拍和弦、罗马级数与功能 T/S/D、借用和弦、五度圈轨迹、Tonnetz |
| 结构 | 自相似矩阵、段落边界、副歌/重复检测、章节叙事（序章 / 蓄势 / 高潮 …） |
| 响度 | LUFS（瞬时/短期/积分）、LRA、True Peak、动态范围、削波检测 |
| 声场 | 立体声宽度、相关度、M/S 比例、Lissajous 相位图 |
| 旋律与扒谱 | 主旋律音高曲线、basic-pitch 分轨 MIDI（可下载）、钢琴卷帘 |

## AI 解读（可选）

分析本身不依赖任何大模型。接入大模型后可以获得：
- **全曲解析**：一句话标题 + 整首歌的总结（风格、结构、情绪曲线、制作亮点）
- **章节解说**：每一章一段文字
- **实时解说字幕**：按时间点写好的「场景变化」解说，播放到对应时刻时以打字机字幕出现（网页的「AI 解读」页和影院模式都有，影院录制的视频里也会带上）
- **问问 AI**：基于这首歌的分析数据自由提问

发给模型的只有分析得到的数字和事件（调性、和弦、段落、分轨进出、响度变化等），**不会上传音频**。

| 服务 | 默认模型 | 环境变量 |
|---|---|---|
| Claude (Anthropic) | `claude-opus-5-5` | `ANTHROPIC_API_KEY` |
| OpenAI | `gpt-5` | `OPENAI_API_KEY` |
| Google Gemini | `gemini-2.5-pro` | `GEMINI_API_KEY` |
| DeepSeek | `deepseek-chat` | `DEEPSEEK_API_KEY` |
| Kimi (Moonshot) | `kimi-k2-turbo-preview` | `MOONSHOT_API_KEY` |
| Grok (xAI) | `grok-4` | `XAI_API_KEY` |

配置方式二选一：
- 网页右上角 **✦ AI** → 填 Key、选模型（可点「获取模型列表」）、「测试连接」、「设为默认」。Key 只保存在本机 `~/.config/sonolens/llm.json`（权限 600），不会发到浏览器。
- 或者启动前设置上表的环境变量。

每个服务都可以改 Base URL，所以任何 OpenAI 兼容的接口（代理、本地 Ollama / LM Studio 等）也能用。
生成结果缓存在 `results/<id>/llm/narration.json`，重新生成会覆盖。

## 流光 · 音乐心象

默认打开的第一个标签页，也可以在影院模式和「实时可视化」的场景列表里选到。一幅画同时承担「好看」和「看得懂」：

| 画面元素 | 对应的音乐信息 |
|---|---|
| 星云底色、亮度、每拍一圈涟漪 | 氛围：大小调 × 能量决定冷暖，和声张力越大越偏绯红，响度决定亮度 |
| 12 个方向的花瓣与光柱（五度圈，每个音固定一种颜色） | 调性与和声：亮起的半圈就是当前调性，转调时光会转向 |
| 离中心的距离、彗尾和火花 | 音高：越靠外越高；白色彗星是人声旋律，绕核心的光团是贝斯 |
| 多边形与白圈 | 当前和弦的组成音与根音；左下角显示和弦名、级数和接下来的走向 |
| 冲击环、光冠、星点闪烁、数拍弧段、三圈莲花纹 | 节奏：底鼓 / 军鼓 / 镲片 / 小节内拍位 / 低中高频段 |
| 流场（流动 / 旋涡 / 绽放 / 奔涌）与换段光波 | 段落：同一类段落用同一种流动方式，最响的段落「奔涌」 |
| 表盘外侧的弧线 | 乐器：每条分轨一条轨道，越响越长越亮 |
| 外环 | 全曲进度：按段落分色，金色刻度是终止式 |
| 拖尾长短、几何感 | 风格：律动清晰、打击感强的音乐更硬朗，旋律和声主导的音乐像墨在水里散开 |

按 H 隐藏文字标注，F 全屏。需要浏览器支持 WebGL2。

## 影院模式（1920×1080 画布）

整首歌会被分成若干章，每一章配一种可视化场景，右侧实时显示解说事实，底部是全曲时间轴。
场景共 30 种（「实时可视化」页另有 3D 声河）：

- 流光 · 音乐心象
- 音高卷帘
- 色度时钟
- 节奏螺旋
- 鼓组网格
- 频谱柱
- 和弦轨道
- 调性轨迹
- 示波器
- 山脊频谱
- Lissajous
- 色度雷达
- 下落音符
- 乐器星系
- 极坐标频谱
- Tonnetz
- 能量流
- 自相似矩阵
- 3D 瀑布
- 声波光环
- 粒子风暴
- 调音台
- 和弦钢琴
- 旋律线
- 节拍脉冲
- 声场频谱
- 响度表
- 万花筒
- 声隧道
- 十二弦

开场有标题页，结尾有「全曲地图」总结页。

快捷键：
- 空格：播放/暂停
- ← →：快进/快退
- S：切换场景
- 1–9：跳转到对应章节
- F：全屏
- A：AI 实时解说开/关（还没有解说时会用默认模型现场生成）
- Esc：退出

「● 录制视频」会把画面和音频录成 mp4 或 webm 并自动下载。

```
  js/cinema/   影院模式：fx.js 工具 · scenes_a/b/c.js 场景 · aura.js 流光 · river3d.js 3D 声河 · stage.js 舞台
results/<id>/  每首歌的分析结果（analysis.json、二进制热图、分轨音频、MIDI）
```
